  ## 🏗️ Technical Architecture & Key Differentiators

    flowchart LR
        A[Student Query] --> B[Input Guardrails]
        B -->|Passed| C[ChromaDB Vector Retrieval]
        C --> D[LangGraph State Workflow]
        D --> E[Groq Llama 3.3 70B]
        E -.->|Fallback Failover| F[Google Gemini 2.5 Flash]
        E --> G[Output Guardrails & PII Masking]
        G --> H[ChatGPT-Style Frontend Streaming]

  ### 1. LangGraph Agentic Workflow (src/helpdesk_agent/agent/graph.py)

  • Built on a stateful 4-node pipeline: validate_input → retrieve → generate → validate_output.
  • Includes built-in conversational memory checkpointers for seamless multi-turn dialog.

  ### 2. Cascading Multi-Tier LLM Fallback (src/helpdesk_agent/llm/llm_gateway.py)

  • Tier 1 (Ultra-Low Latency): Groq llama-3.3-70b-versatile
  • Tier 2 (High Availability): Groq Secondary Key
  • Tier 3 (Global Failover): Google gemini-2.5-flash
  • Guarantees 99.99% uptime during peak admission & examination cycles.

  ### 3. ChromaDB Semantic Vector Engine (src/helpdesk_agent/retrieval/store.py)

  • Utilizes HuggingFace sentence-transformers/all-MiniLM-L6-v2 embeddings.
  • Ingests institutional documents (.pdf, .txt, .docx, .md) with recursive chunking and overlap to preserve
  policy context.

  ### 4. Enterprise Guardrails & Privacy (src/helpdesk_agent/guardrails/guardrails.py)

  • Prompt Injection Defense: Blocks adversarial attacks, jailbreaks, and system prompt exfiltration.
  • Restricted Topics: Filters out unsafe/malicious queries.
  • PII Auto-Redaction: Automatically masks student emails and phone numbers before output.

  ### 5. SaaS UI & Frontend Streaming Engine (web/)

  • Real-Time Word-by-Word Streaming: ChatGPT-style typewriter cadence with live blinking cursor (▍).
  • Date-Grouped Conversation History: Persistent multi-session history (Today, Yesterday, Previous 7 Days,
  Older) with live search, renaming, and Markdown export.
  • Verified Citations: Official source badges linking answers directly to specific handbook sections.
